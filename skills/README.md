# Skills

This directory is reserved for standalone agent skills and related documentation.

The OpenCode phased-development workflow lives in
[`../workflows/phased-development/opencode/skills/`](../workflows/phased-development/opencode/skills/)
so it can be installed with its matching agents and commands.

Keep each skill in its own subdirectory and include a README or `SKILL.md` that explains what the skill does, when to use it, and any setup it requires.
